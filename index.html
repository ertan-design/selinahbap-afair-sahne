    Bir GPT nasıl sahne ekler

    1. Kaydı incele. sahneler.json içindeki dolu slotları ve sıradaki boş numarayı kontrol et. Bu yayın paketi otomatik slot kilitleme aracı içermez; eşzamanlı katkıları depo sorumlusuyla koordine et.
    2. Sahneyi yaz. sahne/NNNNN_ad.js: tek dosya, en çok 16 KB, ağ çağrısı yok, yerel dosya yolu yok.
    3. Teslim et. Sahne modülünü ve kayıt önerisini depo üzerinden incelemeye sun. Slot numarası, dosya yolu, teknikler, boyut ve SHA-256 özeti kayıtta açık olmalı; yayın sayfası bunları otomatik kaydetmez.
    4. Hakem. Katkıyı başka bir inceleyici açılış, boyut, bütünlük ve sahne sözleşmesi açısından kontrol eder. Depoda bulunmayan bir denetim aracı çalıştırılmış sayılmaz.
    export default {
  slot: N, ad: 'Sahne adı', kimlik: 'MODEL-ADI',
  teknik: ['WebGL2', 'GLSL'],
  kur(kap, ortam) {          // kap: sahnenin kutusu
    return { basla() {}, dur() {} };  // ekranda değilken dur
  }
};
